# Korea Stock Lab

yfinance로 국내 주식 10개의 일봉을 수집하는 Streamlit 대시보드입니다.

## 실행 (Windows PowerShell, Python 3.12 권장)

가장 쉬운 방법은 [run_korea_stock_lab.bat](run_korea_stock_lab.bat)을 더블클릭하는 것입니다. 처음 실행할 때만 가상환경과 패키지를 준비한 뒤 Streamlit 사이트를 브라우저에서 자동으로 엽니다. 이미 실행 중이면 새 서버를 만들지 않고 사이트만 엽니다.

PowerShell에서 직접 실행하려면:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

브라우저에서 http://localhost:8501 을 여세요.

삼성전자, SK하이닉스, LG에너지솔루션, 삼성바이오로직스, 현대차, 기아, 셀트리온, KB금융, NAVER, 카카오를 기본 수집합니다. `app.py`의 `STOCKS`에서 변경할 수 있습니다. KOSPI 티커는 `.KS`, KOSDAQ은 `.KQ`를 붙입니다.

- 조회 기간과 비교 종목 선택, 수정종가 수익률 비교
- 조정 전 일봉 캔들, 20/60일 이동평균, 거래량
- 전체/선택 데이터 CSV 다운로드 (Excel용 UTF-8 BOM)
- 수집한 전체 데이터는 `data/stocks.csv`에 저장
- 15분 메모리 캐시, 수동 새로고침, 일부 종목 수집 실패 안내
- `gpt-4.1-mini` 기반 AI 데이터 챗봇: 화면에서 입력한 OpenAI API 키로 현재 선택 종목을 질의
- PDF 업로드 기반 질의: 텍스트 PDF(10MB, 100쪽, 60,000자 한도)를 주식 데이터와 함께 분석
- Yahoo Finance 뉴스와 주가 요약을 바탕으로 AI 보고서 생성 및 SMTP 이메일 전송

Yahoo Finance 연결 및 요청 제한에 따라 수집이 실패할 수 있습니다. 모의 데이터를 대신 표시하지 않습니다. 실시간 시세 서비스가 아니며 각 종목의 마지막 거래일을 표에서 확인할 수 있습니다.

수익률 비교 차트는 공통 거래일 기준이고, 요약 표는 각 종목에서 수집된 첫날과 마지막 날 기준입니다. 가격은 KRW, 거래량은 주 단위입니다.

## AI 데이터 챗봇

사이드바의 **OpenAI API 키**에 본인 키를 입력하면 `AI 데이터 챗봇` 탭에서 질문할 수 있습니다. 키는 Streamlit의 현재 브라우저 세션에서만 사용하며 파일 또는 CSV에 저장하지 않습니다. 챗봇은 현재 선택한 종목의 요약과 최근 15거래일 종가·거래량을 모델에 전달해 답변합니다. 제공 정보는 투자 권유가 아닙니다.

새 브라우저 탭은 기존 탭의 API 키 입력값을 공유하지 않습니다. 새 탭마다 키를 입력해 주세요. 키가 비어 있으면 질문 입력란은 비활성화되며, 인증·권한·사용량·연결 오류는 화면에 구체적으로 표시됩니다.

PDF는 서버 메모리에서 텍스트만 추출하며 디스크에 저장하지 않습니다. 질문을 전송할 때 추출한 텍스트는 OpenAI API로 전달됩니다. 이미지로만 구성된 스캔 PDF와 암호 PDF는 지원하지 않습니다.

## 뉴스 보고서와 이메일

`뉴스 보고서·메일` 탭에서 선택 종목별 Yahoo Finance 최근 뉴스와 수집된 주가 데이터를 바탕으로 보고서를 생성할 수 있습니다. 생성된 보고서는 화면에서 먼저 확인한 후 SMTP 서버, 포트, 보내는 계정, 앱 비밀번호, 받는 이메일을 입력해 전송합니다. 이 값들은 현재 브라우저 세션에서만 사용하며 파일에 저장하지 않습니다. Gmail은 보통 `smtp.gmail.com`, 포트 `587`, STARTTLS와 Google 앱 비밀번호를 사용합니다.
